# Scripts Directory Catalog

## Categories

- **Root scripts/**: Primary operational scripts tied to package.json commands or active pipeline utilities (e.g. deleteOldJobsAndApplications.ts, scanZohoConnected.ts, esetSandboxDb.ts).
- **scripts/audit/**: Analysis, diagnostic breakdowns, data quality, screenshot extraction, and failure categorization scripts.
- **scripts/backfill/**: One-off profile, work history, and data reconciliation/backfill scripts.
- **scripts/sync/**: Multi-DB sync, fixture replication, and database alignment scripts.
- **scripts/archive/**: Deprecated, superseded one-off migration and diagnostic scripts.
